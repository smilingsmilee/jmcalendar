# JMCalendar

A web application for the NUS Japanese Music Club that centralises member availability and helps band leaders schedule rehearsals without conflicts.

## About

JMC is all about mixing and matching musicians into different bands, which is fun until scheduling annoyances arise from being in too many bands. JMCalendar makes rehearsal planning a little less chaotic.

Just submit your availability once, and every band you're in can see when you're free. When you accept a rehearsal invitation, that time slot is automatically marked as unavailable for your other bands, preventing double bookings.

## Stack

- **Language:** Python
- **Frontend:** Streamlit
- **Backend & Database:** Supabase
- **Authentication:** Supabase Auth
